# RNF-020 — Facilidad de Aprendizaje para Usuarios No Técnicos

## Identificación

| Campo | Valor |
|---|---|
| ID | RNF-020 |
| Título | Facilidad de Aprendizaje para Usuarios No Técnicos |
| Categoría | Usabilidad |
| Prioridad | Alta |
| Estado | Pendiente |
| RF asociados | RF-010, RF-012, RF-018, RF-023 |

---

**Descripción**: El sistema debe ser suficientemente intuitivo para que usuarios sin experiencia técnica avanzada puedan realizar tareas básicas (subir fotografía, buscar fotografía, ver calendario) en menos de 15 minutos tras capacitación inicial de 30 minutos.

**Métrica**:

- 80% de usuarios nuevos completan tareas básicas exitosamente en <15 minutos
- Tareas básicas evaluadas:

        Subir fotografía con metadatos
        Buscar fotografía por escena
        Visualizar calendario
        Enviar mensaje en canal
- Tras capacitación inicial de 30 minutos
- Medición con usuarios reales del cliente


**Aplica a**:
- Toda la interfaz del sistema
- RF-010 (Carga de fotografías)
- RF-012 (Búsqueda)
- RF-018 (Calendario)
- RF-023 (Comunicación)

**Estándar/Norma**:
- ISO 9241-11 - Usabilidad

**Método de Verificación**:
- Pruebas de usabilidad con 10 usuarios reales (Script, Vestuario, Maquillaje)
- Sin experiencia previa en Raccord
- Capacitación de 30 minutos
- Asignar 4 tareas básicas
- Medir tiempo de completación y tasa de éxito
- Verificar 80% completa en <15 minutos
