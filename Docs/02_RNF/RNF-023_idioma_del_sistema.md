# RNF-023 — Idioma del Sistema

## Identificación

| Campo | Valor |
|---|---|
| ID | RNF-023 |
| Título | Idioma del Sistema |
| Categoría | Usabilidad / Localización |
| Prioridad | Media |
| Estado | Pendiente |
| RF asociados | General / Transversal |

---

**Descripción**: La versión 1.0 del sistema debe estar completamente en español (Colombia), incluyendo interfaz, mensajes de error, notificaciones y documentación.

**Métrica**:
- 100% de textos de interfaz en español (Colombia)
- 100% de mensajes de error en español
- 100% de notificaciones en español
- Formato de fechas: DD/MM/YYYY
- Formato de hora: 24 horas (HH:MM)
- Moneda (si aplica futuro): COP (Peso Colombiano)
- Uso de vocabulario específico de Colombia (ej: "celular" no "móvil")


**Aplica a**:
- Todas las interfaces del sistema
- Todos los mensajes y notificaciones

**Estándar/Norma**:
- ISO 639-1 (código de idioma: es)
- ISO 3166-1 (código de país: CO)

**Método de Verificación**:
- Revisión manual de todas las pantallas
- Verificar ausencia de textos en inglés u otros idiomas
- Verificar formato de fechas y horas
- Pruebas con usuarios colombianos
