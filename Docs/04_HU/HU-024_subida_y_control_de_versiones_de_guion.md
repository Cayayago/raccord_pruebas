---

## Historia

*Como* Script (continuista),
*quiero* subir nuevas versiones del guion en PDF con control de versiones,
*para* que todo el equipo trabaje siempre sobre la versión correcta.

## Criterios de Aceptación

- El sistema rechaza subir una versión con un número ya existente.
- Al marcar una versión como "En Rodaje y aprobado", esta se vuelve automáticamente la única visible para el rol Usuario.
- El sistema mantiene el historial completo de versiones y permite descargarlas solo a roles autorizados.
- La subida de una nueva versión "En Rodaje" notifica a todo el equipo.
