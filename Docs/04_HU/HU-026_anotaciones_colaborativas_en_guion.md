## Historia

*Como* Jefe de Departamento,
*quiero* anotar el guion con notas y resaltados personales o departamentales,
*para* dejar constancia de detalles importantes sin tener que imprimir el documento.

## Criterios de Aceptación

- El sistema permite tres niveles de visibilidad de anotación: personal, departamental y general.
- Solo el Script puede crear anotaciones generales, y solo jefes de departamento pueden crear anotaciones departamentales.
- Las anotaciones se sincronizan automáticamente entre todos los dispositivos del usuario.
- Cada usuario solo puede editar o eliminar sus propias anotaciones.
